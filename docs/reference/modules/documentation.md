# Documentation generator

Call `DocumentationGeneratorService.generate_documentation(package_path="src/curriculum", use_llm=False)` to build a local AST inventory and module pages. Review status and inspect the generated Markdown and JSON in the configured output directory. See the [verified offline example](../../development/testing.md).
