# Abstract

Course is an educational content repository implemented as typed
Python models, service classes and a local FastAPI application.
The design separates educational records from HTTP routes and from
optional storage and integrations. We document the domain boundaries
and evaluate a local content lifecycle, the HTTP process contract,
and offline package documentation generation. The native extractor
processed 71 Python files and identified 70 modules and 636 method
entries with its model provider disabled. The runtime measurements
describe this checkout and its own fixtures. They establish
reproducibility of a local software path.
