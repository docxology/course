# Discussion

The abstract syntax tree provides an inventory of declared methods.
Behavior still depends on the runtime service contracts, so the
inventory complements an executable course-content check and the
native tests. User-facing documentation should track both the
published interface and the conditions needed to run it.

The fixture covers one local process with in-memory state. Evaluating
persistent deployments, integrations, learning outcomes, accessibility
conformance, and performance at scale requires separate datasets and
methods.
